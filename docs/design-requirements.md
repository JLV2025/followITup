# 综合报告看板 — 设计需求文档

> 版本：v1.0  
> 日期：2026-07-28  
> 状态：待评审

---

## 1. 设计目标

本文档定义综合报告看板（Dashboard）的视觉、交互与信息架构需求。此看板是用户在浏览器中看到的**第一屏**，承担以下职能：

- 用户打开后 **3 秒内**感知"今天是否有需要关注的问题"
- 跨项目汇总关键指标，无需逐个进入项目查看
- 通过一次点击进入任意项目的详情页
- 支持按年度切换数据范围，满足长期管理需求

**核心设计原则**：

1. **3 秒安全感**：统计卡片传递"有事/没事"信号
2. **高信息密度，严格秩序**：类似 Bloomberg 终端或报纸头版的排版逻辑
3. **颜色克制**：95% 灰色调 + 5% 功能色彩，让风险标识真正醒目
4. **一个点击到详情**：总览 → 项目详情只有一层跳转

## 3. 区块详细设计

### 3.1 顶栏

**高度**：48px  
**背景**：白色 `#FFFFFF`，底部 1px 分割线 `#E5E7EB`

| 元素 | 位置 | 说明 |
|------|------|------|
| Logo / 应用名 | 左对齐 | 字体 Inter, 16px, weight 600 |
| 通知铃铛 | 右侧 | 有未读通知时显示红点，点击展开下拉列表 |
| 用户名 | 通知右侧 | 14px，显示当前登录用户名，点击可退出 |

**通知下拉列表**：
- 最多显示 5 条
- 每条格式：`图标 + 项目名 — 事件描述 + 时间（如 "2小时前"）`
- 示例：`🔴 CRM系统上线 — 2项任务已超期  · 1天前`
- 点击跳转到对应项目详情

### 3.2 统计卡片区

**布局**：4 列等宽，间距 16px  
**高度**：约 100px

每张卡片结构：
```
┌─────────────────┐
│  有风险          │  ← 标签，12px，灰色
│   2             │  ← 数值，36px，weight 700
│  ▔▔▔            │  ← 底部装饰线，2px，与状态颜色一致
└─────────────────┘
```

| 卡片 | 正常时颜色 | 异常时颜色 | 点击行为 |
|------|-----------|-----------|---------|
| 活跃项目 | 深灰 `#1A1A1A` | — | 无（纯统计） |
| 有风险 | 绿色 `#22C55E`（数值为 0） | 红色 `#EF4444`（数值 ≥ 1） | 点击跳转到筛选：仅看有风险项目 |
| 本周到期 | 深灰（可接受） | 琥珀 `#F59E0B`（≥ 5 项时） | 点击跳转到里程碑详表 |
| 整体完成 | 绿色（≥ 80%） | 灰色（< 80%），卡片底部加进度环 | 无 |

**交互细节**：
- 异常数值（如风险数 ≥ 1）使用微弱的脉冲动画（pulse），循环 2 次后停止，吸引注意力
- 卡片背景 `#FFFFFF`，细边框 `#E5E7EB`，hover 时阴影加深

### 3.3 项目状态卡片列表

**位置**：左侧双栏区，占宽度 55%  
**排序**：有风险 > 本周有截止日 > 其余正常，同组内按项目名称排序

每张卡片结构：

```
┌─────────────────────────────────────────────────┐
│ 🔴 CRM系统上线                          [详情 →] │
│ 进度 ████████████░░░░░░░░░ 55%                  │
│ 下个节点: 系统验收测试  08-15  负责人: 张三      │
│ ⚠ 2项任务已超期                                  │
└─────────────────────────────────────────────────┘
```

| 元素 | 设计规格 |
|------|---------|
| 状态指示灯 | 项目名左侧，直径 8px 圆点：`🟢 #22C55E` / `🟡 #F59E0B` / `🔴 #EF4444` |
| 项目名 | 14px, weight 500, `#1A1A1A` |
| 详情链接 | 右侧对齐，12px，蓝色 `#3B82F6`，仅 hover 时显示 |
| 进度条 | 高度 6px，圆角 3px。背景 `#F3F4F6`，填充色与项目状态灯颜色一致 |
| 进度数字 | 进度条右侧，12px，`#6B7280` |
| 下一节点 | 13px，`#6B7280`。格式：`里程碑名 + 日期 + 负责人` |
| 警告信息 | 若有超期任务则显示，13px，红色 `#EF4444` |
| 左侧装饰线 | 3px 宽竖线，仅在有风险/超期的项目卡片左侧显示。红色或琥珀 |
| 卡片背景 | `#FFFFFF`，圆角 8px，阴影 `0 1px 3px rgba(0,0,0,0.04)` |
| 卡片间距 | 8px |

**交互**：
- 整张卡片可点击（cursor: pointer），跳转到项目详情甘特图页
- Hover 时卡片阴影加深 + 左侧装饰线加宽至 5px

### 3.4 时间线概览（迷你甘特图）

**位置**：右侧双栏区，占宽度 45%  
**默认刻度**：月（12 个月全景）  
**交互**：滚轮缩放（月 → 周）、拖拽平移、点击项目线跳转

```
              Q1          Q2          Q3          Q4
              1月 2月 3月 4月 5月 6月 7月 8月 9月 10月 11月 12月
                                 │
CRM系统上线    ████████████████████            ← 进度条，已完成=深色
IT基础架构     ░░░░░░████████████████████      ← 浅灰=未开始，主题色=进行中
OA流程优化     ░░░░░░░░░░██████████
灾备中心       ░░░░░░░░░░░░░░░░░░████████████
                                 │
                              今日线
```

| 元素 | 设计规格 |
|------|---------|
| 时间轴头部 | 显示季度/月份标签，12px，`#9CA3AF` |
| 项目名称 | 左侧固定列，13px，右对齐，宽度 120px |
| 项目条形 | 高度 20px，圆角 4px。已完成部分 `#3B82F6`，进行中 `#93C5FD`，未开始 `#F3F4F6` |
| 里程碑标记 | 小菱形 `◆`，8×8px，放置在日期对应位置，颜色 `#1A1A1A` |
| 今日线 | 贯穿整个图表区域的竖线，`#EF4444`，1px，虚线 `dashed` |
| 网格线 | 月份之间有极淡的竖线 `#F3F4F6`，1px |
| 背景 | `#FFFFFF` |

### 3.5 底部三栏

底部三栏等宽，各占约 33%。

#### 3.5.1 任务状态分布（环形图）

- **图表类型**：Donut chart（环形图），外径 100px，内径 65px
- **环形中间**：显示任务总数，如 "86 项"，16px, weight 600
- **颜色分段**：绿色（正常） / 橙色（有风险） / 红色（超期）
- **图例**：环形下方水平排列，格式：`🟢 78 正常  🟠 5 有风险  🔴 3 超期`
- **字体**：图例 12px, `#6B7280`

#### 3.5.2 近期里程碑

- **标题**："即将到来"，14px, weight 600
- **数据范围**：未来 14 天所有项目的里程碑
- **列表项格式**：

  ```
  07-30  CRM系统上线             · CRM
  08-02  安全验收测试             · IT基础
  08-05  灾备方案评审             · 灾备中心
  ```

- 日期：12px, weight 500, `#1A1A1A`
- 里程碑名：13px, `#1A1A1A`
- 所属项目：12px, `#9CA3AF`，前缀 `·`
- 关键路径上的里程碑前加 `◆` 红色菱形标记
- 最多显示 8 条，超过的显示 "+ N 项更多"
- **点击里程碑名**：跳转到对应项目的甘特图，定位到该任务

#### 3.5.3 我的待办

- **标题**："我的待办"，14px, weight 600
- **数据范围**：当前用户被分配的所有未完成任务，跨项目
- **列表项格式**：

  ```
  ☐ CRM需求确认文档评审          明天
  ☐ 安全加固方案编写              07-31
  ☐ 灾备网络拓扑设计              08-05
  ```

- 每项前有可点击的勾选框（12px × 12px），勾选后标记完成 + 划线
- 任务名：13px，`#1A1A1A`。超期任务名显示红色
- 截止日期：12px，右对齐。正常为 `#6B7280`，超期为 `#EF4444`，即将到期（≤3天）为 `#F59E0B`
- 最多显示 5 条，超过的显示 "+ N 项更多"

## 4. 年度切换

**位置**：统计卡片上方，紧邻顶栏下方

```
2024 年  |  2025 年  |  ● 2026 年（当前）
```

| 元素 | 设计规格 |
|------|---------|
| 显示逻辑 | 列出有项目数据的所有年份，当前年份默认选中 |
| 未选中年份 | 13px，`#9CA3AF`，下划线样式（border-bottom: dashed） |
| 选中年份 | 13px，weight 600，`#1A1A1A`，无下划线 |
| 分隔符 | `|` 号，`#E5E7EB` |
| 切换行为 | 整个看板的数据范围跟着切换（统计数字、项目列表、甘特图、里程碑皆切换） |
| 历史年份 | 项目列表默认折叠，只显示统计摘要（项目数、完成率） |
| 跨年项目 | 以实际结束日期所属年份归类；若未结束，归入当前活跃年份 |

## 5. 视觉风格规范

### 5.1 底色与质感

```
全页背景色： #FAFAF9  （暖白，略带米色调，不刺眼）
CSS 纹理：   叠加 CSS blur-noise（透明度 2-3%），模拟打印纸触感
卡片背景：   #FFFFFF
卡片边框：   1px solid #EBEBE8
卡片阴影：   0 1px 3px rgba(0,0,0,0.04)
```

纹理 CSS 示意：

```css
body::before {
  content: "";
  position: fixed;
  inset: 0;
  opacity: 0.025;
  background-image: url("data:image/svg+xml,..."); /* 极细噪点 */
  pointer-events: none;
  z-index: 9999;
}
```

**目的**：让界面看起来像精装书的扉页 — 白，但不是屏幕的冷白色。

### 5.2 配色系统

| 用途 | 色名 | 色值 | 使用场景 |
|------|------|------|---------|
| 主文字 | near-black | `#1A1A1A` | 标题、项目名、卡片数值 |
| 次文字 | mid-gray | `#6B7280` | 描述文字、进度数字 |
| 辅助文字 | light-gray | `#9CA3AF` | 标签、时间戳、占位符 |
| 状态—正常 | success-green | `#22C55E` | 状态灯、进度条、正常标识 |
| 状态—有风险 | warning-amber | `#F59E0B` | 状态灯、进度条、风险标识 |
| 状态—超期 | danger-red | `#EF4444` | 状态灯、今日线、超期标识 |
| 强调/链接 | accent-blue | `#3B82F6` | 链接、详情按钮、进度条填充 |
| 边框 | border-gray | `#E5E7EB` | 卡片边框、分割线 |
| 背景 | bg-light | `#F3F4F6` | 进度条背景、未开始任务 |
| 卡片底色 | card-white | `#FFFFFF` | 所有卡片和面板 |
| 页面底色 | page-warm | `#FAFAF9` | 全页背景 |

**配色使用原则**：
- 一屏上 95% 面积为灰色调
- 仅在状态指示器、关键数字、图表数据点使用彩色
- 红色仅用于需要用户注意的少数元素

### 5.3 字体系统

**字体栈**：

```css
/* 标题、数字 */
--font-display: "Inter", "Microsoft YaHei UI", "PingFang SC",
                "Hiragino Sans GB", "Microsoft YaHei",
                "Source Han Sans CN", "Noto Sans SC",
                -apple-system, BlinkMacSystemFont, sans-serif;

/* 正文、UI 文本 */
--font-body: "Inter", "Microsoft YaHei UI", "PingFang SC",
             -apple-system, BlinkMacSystemFont, sans-serif;
```

**选型理由**：
- **Inter**：数字等宽、字形清晰，18 种字重，特别适合统计数字
- **Microsoft YaHei UI**：Win10/11 为 UI 优化的中文字体，字距紧凑，屏幕可读性优于普通雅黑

**字号体系**：

| 层级 | 大小 / 字重 | 用途 |
|------|------------|------|
| XL | 36px / 700 | 统计卡片大数字 |
| L | 24px / 600 | 页面标题 |
| M | 16px / 600 | 区块标题（"项目状态总览"等） |
| S | 14px / 400–500 | 正文、项目名、任务描述 |
| XS | 12px / 400 | 辅助文字、日期、标签、备注 |

### 5.4 间距体系

采用 4px 基准间距：

| 间距 | 数值 | 用途 |
|------|------|------|
| xs | 4px | 紧密关联的元素之间 |
| sm | 8px | 卡片内元素、列表项之间 |
| md | 16px | 卡片之间、区块内边距 |
| lg | 24px | 区块之间 |
| xl | 32px | 页面级外边距 |
| 2xl | 48px | 顶栏高度 |

## 6. 响应式说明

本应用面向桌面端使用（1920px 和 1366px 为主流分辨率），**暂不做移动端适配**。响应式仅需覆盖以下断点：

| 断点 | 布局调整 |
|------|---------|
| ≥ 1440px | 完整双栏 + 底部三栏 |
| 1024–1439px | 双栏改为上下堆叠，底部三栏保持 |
| < 1024px | 所有区块上下堆叠 |

## 7. 页面跳转流程

```
综合看板 (Dashboard)
  │
  ├── 点击项目卡片 → 项目详情页 (/project/:id)
  │     ├── 甘特图 Tab（默认）
  │     ├── 任务列表 Tab
  │     ├── 成员管理 Tab
  │     └── 项目设置 Tab
  │
  ├── 点击统计卡片"有风险" → 看板筛选：仅显示有风险项目
  ├── 点击统计卡片"本周到期" → 看板滚动到近期里程碑区
  ├── 点击迷你甘特图项目线 → 项目详情页 (/project/:id)
  ├── 点击近期里程碑 → 项目详情页，定位到对应任务
  ├── 勾选待办 → 原地完成，不跳转
  └── 点击通知 → 对应项目详情页
```
