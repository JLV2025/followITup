# 项目周报生成

## 工作流程

1. 从看板数据中提取所有活跃项目的关键指标：
   - 项目名、整体状态灯（红/黄/绿）
   - 总任务数、已完成数、完成百分比
   - 超期任务数（按天数列出超期最久的 3 个）
2. 对比上周基线（若有）输出变化：推进了哪些任务、哪些延迟了
3. 汇总本周到期的里程碑和下周即将到期的里程碑
4. 列出风险项：红色/橙色状态的原因
5. 按以下格式输出周报：

```
# 项目周报 — YYYY年第WW周

## 总体概览
- 活跃项目：N 个
- 有风险项目：N 个
- 本周完成任务：N 项
- 超期任务：N 项

## 各项目状态

### 🟢/🟡/🔴 [项目名]
- 进度：XX%
- 本周进展：...
- 下周关键节点：...
- 风险/阻塞：...

## 需要管理层关注的事项
1. ...
2. ...

## 附录：下周到期的里程碑
| 日期 | 里程碑 | 项目 |
|------|--------|------|
```

## 注意事项

- 风险项必须诚实，不粉饰
- 已完成的项目可以省略，除非有复盘价值
- 对比基线的变化要用实际数据，不要笼统描述
